# 画板纪要的编辑审美

这份标准约束的是编辑判断，不是某一篇录音的版式。画板要复刻的是钉钉样例的工作方式：先找到主线，再用足以支撑主线的事实组织视觉层级，让读者不打开逐字稿也能理解内容。

## 先分清硬约束与审美判断

- **卡片高度是硬约束**：所有容器由可见内容决定高度，同一行可以为对齐共享该行最大高度；不同的行和板块不能继承固定高度，不能产生无意义留白。
- **信息密度是审美判断**：它取决于录音是否真的包含值得保留的机制、事实和例子。**不设置全局字数下限**，也**不设置全局卡片数量下限**。访谈里的一个关键反例，可能比十条泛泛结论更有价值。

## 独立可读性测试

盖住正文纪要，让画板**脱离逐字稿**单独接受检查。读者应能回答：

1. 这段录音解决什么问题？
2. 核心判断是什么，为什么成立？
3. 它怎样运转或怎样执行？
4. 哪个事实、例子或限制最值得记住？

如果画板只能让人复述几个栏目名，不能解释录音的核心逻辑，它就是欠解释；不能因为画面整齐而通过。

## 证据的选择

先找主线，再为重要判断挑选解释增益最高的证据。解释增益指一条信息加入后，读者更能理解“为什么、怎么做、在什么条件下成立”。优先考虑：

- **机制**：系统或决策究竟怎样运转；
- **例子或反例**：抽象判断在哪个真实情境里显形；
- **数字或尺度**：变化幅度、时间、数量、概率或成本；
- **专有名词或系统**：准确命名工具、组件、方法和概念；
- **限制、不确定性或边界**：什么情况下不能推出同样结论；
- **因果关系**：A 如何导致 B，中间经过什么环节。

不要为了“覆盖全面”平均分配空间。一个证据如果只是换一种说法重复结论，删掉；一个小例子如果能解释整套机制，给它更显眼的位置。所有事实必须能回到来源 segment，不能为提高密度编造信息。

## 扫读层级

默认阅读路径是：**主题 → 判断 → 证据 → 含义**。

- 主题说明当前回答哪个问题；
- 卡片标题直接说判断，不要只有名词的标题；
- 正文用事实、机制、例子或限制让判断站住；
- takeaway 只在它能说明后果、选择或含义时出现，不重复标题。

视觉强调也服从这条路径。颜色和加粗应落在数字、动作、系统名和约束上；装饰性标签、无含义图标和无依据的口号会分散注意力。

## 失败形态

- **口号化卡片**：标题很响，正文只有“提升效率、持续进化、形成闭环”。
- **只有名词的标题**：如“技术架构”“数据能力”，读者不知道作者对此作了什么判断。
- **证据变体重复**：三条 bullet 只是同一句话换词。
- **装饰性标签**：为了填角落添加“核心、关键、领先”等标签。
- **为了塞内容缩小字号**：应改写、拆组或换视觉结构，不能牺牲可读性。
- **像模板而不像这段录音**：换一份逐字稿仍能原样套用大半标题和结论。

## 多轮审美校准

每轮都要先渲染，再做编辑判断：

1. 看**全图**：主线是否一眼可见，板块之间的权重是否符合内容；
2. 看**局部放大**：每个重要判断是否有证据，字号、行长和留白是否舒服；
3. 有用户给出的**参考样例**时，比较信息取得感、层级和阅读节奏，不做像素级临摹；
4. 标出**欠解释**、**过度拥挤**、证据重复和**无意义留白**；
5. 优先重写和重组内容，再处理局部尺寸；不要靠缩字或统一加高解决；
6. 如果仍有明显差距，**至少再修改一轮**，并重新查看本地 PNG；写入飞书后还要查看 live PNG。

停止条件不是“校验器通过”，而是画板既能独立讲清录音，又没有明显的编辑杂质和版式缺陷。
