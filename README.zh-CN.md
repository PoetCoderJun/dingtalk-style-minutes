# DingTalk-style Minutes

**把任意受支持的中文录音变成钉钉闪记风格的飞书图文纪要。**

这不是另一款录音软件。手机、AI 录音笔、相机或会议软件负责采集声音；本项目负责把声音整理成一份可以阅读、编辑和回查来源的飞书文档。

> 本项目借鉴钉钉 AI 纪要的信息架构，是独立开源项目，与钉钉及阿里巴巴不存在隶属或官方合作关系。

最终文档严格包含：

1. `一、内容概览`：一段话说明录音讲了什么；
2. `二、AI 纪要`：可编辑飞书画板，以及“判断 → 证据”的层级纪要；
3. `三、完整转写`：概述、语义章节、说话人、章节摘要、时间戳和完整原文。

项目的核心差异不是“也能转写”，而是：

- 画板结构随内容变化，不固定生成思维导图；
- 每条视觉判断保留 `source_segment_ids`；
- 完整转写不得漏段、重复或重排；
- 画板是飞书中的可编辑节点，不是截图；
- 卡片高度由内容决定，不用固定高度制造大片空白。

完整安装、依赖、测试、隐私和限制说明见 [英文 README](README.md)。
