# Content routing

Infer structure from rhetoric, not duration alone.

| Recording signal | Primary structure |
|---|---|
| A thesis defended with reasons | argument: thesis, evidence clusters, objections, conclusion |
| Instructions in execution order | tutorial: prerequisites, process, pitfalls, result |
| Multiple speakers and questions | interview: themes, positions, notable quotes, synthesis |
| Decisions, owners, unresolved items | meeting: context, decisions, rationale, actions, open questions |
| Concepts taught with examples | lecture: concept hierarchy, mechanisms, examples, implications |
| Events changing over time | story: setup, turning points, outcome, lesson |
| Evaluation of a product/idea | review: criteria, evidence, strengths/weaknesses, verdict |
| Mixed signals | mixed: preserve the dominant spine, add only necessary secondary modules |

Choose visual grammar per section:

- parallel ideas → cards;
- sequence/dependency → process or timeline;
- genuine opposing positions → comparison;
- decision-relevant numbers → metrics;
- memorable exact language → quotes;
- one integrated conclusion → synthesis.

Do not force metrics when the recording has no decision-relevant figures. Do not create a timeline from mere chronological speech. Do not invent an opposing side for visual balance.
